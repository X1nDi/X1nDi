## What I build

I enjoy taking an idea from a rough prototype to something people can actually use: desktop utilities, bot-driven workflows, integrations, and server-side game mechanics.

- **Telegram & MAX** — automation and bridge applications with a clear UI and persistent state.
- **Desktop software** — Windows tools for managing a PC remotely through a Telegram bot.
- **Minecraft plugins** — Java plugins for improving moderation and gameplay on servers.
